# oneframework — ядро

Договор, сборщик и рантайм. Приложение объявляется **на любом языке**,
собирается и работает этим.

Само по себе ядро приложений не пишет — писать на нём не на чем. Оно принимает
**пакет объявления** (JSON, описанный в [`protocol/`](protocol/)) и делает из
него работающее приложение: базу SQLite, PWA, APK.

Пакет печатает привязка вашего языка:

| язык | репозиторий |
|---|---|
| Python | [oneframework-python](https://github.com/vlad-anisov/oneframework-python) |
| Kotlin | [oneframework-kotlin](https://github.com/vlad-anisov/oneframework-kotlin) |
| JavaScript | [oneframework-js](https://github.com/vlad-anisov/oneframework-js) |

## Что внутри

```
protocol/    договор: конверт объявления, документ вида, выражения,
             типы полей, логика, провод — одно описание на все языки
src/build/   сборка: пакет → база, манифест, значки, vite, модули WASM
src/         рантайм: SQLite, определения, поля, экраны, обмен, часы
web/         оболочка и рисовальщик — React поверх Framework7
android/     хост Capacitor
ios/
```

## Что нужно на машине сборки

**node** — и всё. Для приложений на Kotlin ещё компилятор Kotlin, для питона на
устройстве — сам питон. На устройство не едет ни то ни другое: туда попадает
собранное приложение.

## Проверки

```bash
npm install
python3 -m pytest tests -q      # правила ядра
npx playwright test             # сквозные, на собранном приложении
```

**Проверки написаны на питоне, хотя ядро — нет.** Это наследство: сюита росла,
когда эталоном был питоновский рантайм, и половина на JavaScript сверялась с ним
построчно. Питоновской половины давно нет, оснастка осталась. Перенести её на
прогонщик JavaScript — задача, а не тайна.
